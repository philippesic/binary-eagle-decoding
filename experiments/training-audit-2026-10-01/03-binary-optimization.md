# Binary sign optimization, STE and initialization audit

Date: 2026-10-01. Repository source: `d725fc88` (`d725fc8`), read from the shared main checkout. Scope: read-only source and primary-source literature audit; no training, model execution, GPU access or live-pipeline modification. Numerical consequences below are algebraic deductions, not observed gains. The live status at this revision records zero optimizer steps, so optimizer efficacy has not yet been measured.

## Verdict and priority

**First measure whether the current sign inertia actually limits native acceptance, then compare one lower-inertia Adam control.** The strongest published causal-LLM alternative is a ParetoQ-style weight-unit STE with learned scales, but it changes several coupled optimization choices and deserves a separate, bounded second experiment. Bop is a credible memory-saving fallback with much weaker task-transfer evidence. ReCU and indiscriminate removal of the clipped STE are low priority because this implementation already projects weights into the trainable interval. More sign flips alone do not establish useful learning.

The expensive capture, target/verifier, row deployment representation, masks, ancestry and current independent A8/A1 lanes should remain fixed. Q4_0 remains the acceptance, latency and throughput comparison target. None of these papers demonstrates improved EAGLE acceptance or SM75 request throughput.

## What the current implementation actually does

The constructor argument is misleading if read alone. `RowBinaryLinear` clones its supplied weight, but the **full-model initializer explicitly passes ±0.5**: `install_joint_linears` in `src/w1a1_eagle/recurrent_qat.py:270–276`. Original dense F16 weights supply signs and mean-absolute F32 row scales; their elementwise magnitudes are discarded. `continuous_qat.py:230–244` installs this row model and deep-copies it for A1. Both lanes therefore start with identical signs, scales and latent magnitudes, then have independent optimizer/RNG state. Candidate-D group128 initialization from packed arrays is ±1; that is a different initialization path, not the current continuous row experiment.

Each of 218,234,880 latents uses a hard ±1 forward, zero positive, and an inclusive clipped identity STE, derivative `1[|z| <= 1]`. There are 65,280 independent nonnegative row scales per lane. The continuous optimizer uses AdamW, sign LR 1e-3, scale LR 1e-5, default betas .9/.999 and epsilon 1e-8, zero decay and `foreach=False`; joint sign-and-scale global gradient clipping is 1. The first 100 paired updates warm up linearly; LR is subsequently constant. Every update clamps latents to [-1,1] and projects negative raw scales back to zero. Consequently a latent at either boundary remains differentiable; permanent out-of-interval STE death is prevented.

Proposal-unroll state and K/V remain attached; rebuilt context is a declared no-gradient boundary. CE uses captured candidate-D exact prefixes and fresh native labels/features, not current-student trajectories. These distribution and truncation boundaries must remain fixed in an optimizer comparison.

The latest A1 correction is also material: `RowBinaryLinear.forward` computes hard native-order integer sign dots, then weight scale and activation scale, and attaches gradients from the original dequantized-value surrogate. It avoids a scaled floating reduction cancellation residual changing a later sign. Any optimizer/STE replacement must preserve that hard forward and its raw-bit negative-subnormal/zero convention, including scale-zero backward behavior. Removing the detach correction as an incidental refactor would confound the experiment.

## Mechanism and gradient analysis

For one row, write `y = alpha * sum_j s_j * xhat_j`, `s_j=sign(z_j)`, with upstream derivative `delta`. Ignoring the frozen bias, the current surrogate gives

```text
dL/dz_j     = alpha * sum_t delta_t*xhat_tj * 1[|z_j|<=1]
dL/dalpha   = sum_t delta_t * sum_j s_j*xhat_tj
dL/dx_tj    = alpha * s_j * delta_t
```

The latter flows through the activation identity STE. Scale gradients aggregate a whole input row; individual sign gradients include alpha. Large fan-in, cancellation, recurrence and layer sensitivity therefore affect sign/scale balance. The nominal 100:1 LR ratio is not the ratio of effective weight changes. Adam normalizes approximately constant gradient magnitudes, but epsilon, changing scales, global clipping and evolving second moments prevent exact cancellation of this coupling. Joint global clipping can be dominated by a few scale or layer tensors and modifies the gradient sequence entering every Adam moment; it should be logged by parameter family before any normalization change is justified.

At **weight scale alpha=0**, sign and upstream-input gradients vanish, while the additive scale gradient can remain nonzero. Its forward derivative at exact zero is one, allowing recovery when the loss requests a positive scale; projection prevents negative scales. At **A1 activation scale beta=0**, the dequantized activation is zero, so that projection's sign/weight-scale gradients vanish, but the identity activation STE can still send an upstream-input gradient if alpha is nonzero. The native hard-dot branch alone does not express this derivative; the existing surrogate correction preserves it. An alpha-normalized optimizer must explicitly define zero-scale behavior rather than divide by zero or silently replace the forward scale with epsilon.

Latent magnitudes are optimizer confidence/inertia, not deployed weight magnitudes: any positive rescaling that preserves signs leaves the hard forward unchanged. Under unclipped magnitude-independent gradients, jointly rescaling initialization and LR preserves sign trajectories; fixed projection bounds, magnitude-dependent gates, Adam epsilon and scale dynamics qualify that argument here. Under an ideal constant coherent Adam gradient much larger than epsilon, updates are approximately the sign LR. Starting at ±0.5 therefore needs about **550 updates including the 100-step warmup** to first cross zero. This is a diagnostic illustration, not a lower bound or prediction: momentum reversals, normalization and varying gradients can change it substantially. An inferred 1,000-step delay based on ±1 would describe the wrong lane.

Higher sign LR reduces inertia and the cost of changing an initially wrong bit, but also reduces resistance to minibatch noise and reversals near zero. Count net Hamming distance from initialization, unique changed bits, flip-back frequency and sustained disagreement over checkpoints; cumulative flip count counts chattering repeatedly. Increasing LR because flips are absent before the initial-inertia traversal time is unjustified. Initializing with raw source magnitudes would accelerate small dense weights disproportionately and encode a new importance prior; it is not merely restoring a missing floating representation. Source magnitude distributions have not been measured in this audit.

The [official ParetoQ quantizer](https://github.com/facebookresearch/ParetoQ/blob/7b36b8de958aada6508e620c8dc544e6ed6c39b4/models/utils_quant.py), pinned to author revision `7b36b8de958aada6508e620c8dc544e6ed6c39b4`, clarifies an important distinction: binary forward `alpha*sign(u)` has backward `dWq/du=1[|u/alpha|<=1]`, excluding the multiplicative alpha in our z-gradient. The code includes endpoints; paper Equation4 uses a strict boundary. Scale gradients sum sign times upstream derivative and multiply by `1/sqrt(input.numel())` for binary; the released implementation uses the full weight tensor's element count even for row scales. It floors alpha at1e-5 and uses `input.sign()`, whose exact-zero convention differs from ours. Its [initializer at the same revision](https://github.com/facebookresearch/ParetoQ/blob/7b36b8de958aada6508e620c8dc544e6ed6c39b4/train.py) retains pretrained dense weights and initializes scales from row mean absolute weights. Those choices require explicit adaptation; copying them is not a contract-preserving drop-in.

## Ranked bounded alternatives

1. **Lower-inertia Adam, same forward/STE.** Compare current ±0.5 against ±0.1 at the same LR, scales, projection and budget. This isolates an optimization-only prior with identical checkpoint-zero exports, no extra state and negligible initialization cost. It is a proposed mechanism test, not a published numerical recipe. An alternative modest LR increase tests a related effect, but do not vary both simultaneously. If successful, test source-relative confidence against a constant initialization matched for mean inertia, with bounded positive magnitude and unchanged zero sign; raw source magnitudes otherwise confound global inertia and its distribution.

2. **ParetoQ-inspired weight-unit STE and scale-gradient normalization.** Preserve `alpha*sign` deployment and native A1 hard ordering while independently defining dense-unit latents, clipping gates, source initialization and normalized scale gradients. Test one component at a time after the inertia control. Persistent state remains essentially Adam's current size; custom backward adds elementwise work, not another large optimizer state. Purely multiplying every sign gradient by a constant has limited leverage under Adam; changed clipping masks and relative sign/scale histories matter more. Define recovery at alpha0 and inclusive boundaries first. Unprojected dense-unit clipping can create the very dead zone currently avoided.

3. **Bop for signs, Adam for scales.** Use the same recurrence and forward, explicitly differentiating with respect to the binary sign rather than a gated latent. Choose thresholds from training-only gradient statistics; scale coupling makes paper tau values nonportable. Keeping signs in F32 plus one EMA instead of a latent plus two Adam moments saves about0.813GiB per lane,1.626GiB for two lanes, before buffers/temporary masks; packed training signs could save more but require additional implementation. This does not speed dense simulation matmuls. Bop2ndOrder adds second-moment normalization, but [its published evidence](https://arxiv.org/abs/2104.05124) is also CV; ordinary Adam already supplies that normalization, so it is not an immediate extra priority.

4. **Restricted discrete fitting, only after a failed bounded STE study.** A scalar-sign analogue of PV can select a small gradient-ranked subset, propose flips and alternate row-scale updates, constraining effective-weight change. For fixed layer inputs, flipping coordinate j changes row outputs by `-2*alpha*s_j*x_j`; squared reconstruction loss changes by `-4*alpha*s_j*<e,x_j> +4*alpha^2*||x_j||^2`. This enables decisive local sign decisions without pretending a sign derivative is exact. It optimizes a reconstruction proxy, not recurrent CE or acceptance. Re-evaluating CE for many proposals is expensive; limited subset/trust controls and extra forward/search costs must be charged to the budget. Full covariance storage and exhaustive218M-coordinate sweeps are inappropriate here.

ReCU, SGD/momentum, generic second-order optimizers and sign-only Adam variants are deferred. They either lack matching transformer evidence, reintroduce scale-sensitive step tuning, change initial deployed signs through standardization, or increase state/derivative cost before a concrete deficiency is established.

## Smallest decisive comparison and rejection criteria

After the existing launch gates and baseline training evidence are available, use a **separate frozen fork**, not an exact-resume mutation. For each width compare the current recipe to ±0.1 inertia only, sequentially on the one owned GPU. Freeze the same permitted train rounds/order, supported CE masks, loss reduction, context rebuild, unroll depth, row scales, optimizer/warmup, native runtime, export convention, seeds and evaluation prompts. Admit byte-identical checkpoint-zero packed signs/scales and native choices before optimization. Freeze a4,000-paired-update ceiling and an equal wall-time/data-row ceiling per arm; report both completed supervised rows and optimizer seconds. This is a proposed bounded screen, not a claim that4,000 updates suffice. Checkpoints0/1000/2000/4000 permit inspection beyond the idealized crossing delay without a dense hyperparameter search.

Use training-only diagnostics to test the inertia hypothesis: per-layer normalized update/moment-to-inertia distributions, clipping contribution by sign/scale family, near-zero/bound fraction, dead scale fraction, net/unique/persistent flips and flip-backs. CE decrease before flips can come entirely from scale fitting. Native development accepted tokens/round, acceptance by proposal depth and prompt/domain, and proposal distributions decide quality. Teacher-forced CE remains a diagnostic on a different prefix distribution. Evaluate the fixed24 prompts first, then use a predeclared wider unsealed development subset only for one promising checkpoint per arm; account for repeated selection. A second seed is required for promotion when a narrow screen is close.

Reject lower inertia if it raises chattering or worsens native acceptance despite improving CE; reject any candidate with nonfinite state, changed target/verifier behavior, wrong ancestry, failed row/cache/export/numeric gates, or gradient-zero regression. Reject a claimed efficiency improvement if it used extra rows, updates, search forwards or runtime changes without accounting. A positive optimization result must eventually improve a matched native Q4_0 acceptance/latency/total-throughput comparison; SM75 throughput requires actual RTX2080Ti authorization and measurements. No sealed final data is needed to make this bounded research decision.
